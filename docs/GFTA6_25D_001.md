## Two presentation modes

| Mode | Description | Status |
|---|---|---|
| Classic 2D | Existing Suburbania Canvas presentation | Default |
| Raised 2.5D | Upstream-projected building roofs, side faces, shadows and car/building depth ordering | Opt-in |

Use **VIEW: CLASSIC 2D** / **VIEW: RAISED 2.5D** in the game toolbar.
The view switch is a browser presentation setting only; it is never written
to the deterministic game snapshot.

### Coordinate contract

GFTA6 world coordinates are X/Y, with screen Y increasing down.
VANILLAJS projection represents the ground plane as X/Z and vertical
height as Y. We map:

- GFTA6 X → projection X
- GFTA6 Y → projection Z
- authored building floor hint × 14 → visual height Y

The upstream camera uses an orthographic/oblique ground projection that
leaves ground coordinates exactly unchanged. Raised height affects roof
vertices, shadows and visual occlusion, **not** the collision footprint.
The adapter is `src/scene25d.js`.

### Visibility limitation

Depth ordering uses the upstream `depthKey` (the ground-facing edge of
each rectangle). The car is inserted into that painter sequence using its
own ground Y coordinate. This produces meaningful occlusion on ordinary
non-intersecting city blocks but is not a general 3D z-buffer and does not
solve intersecting polygon geometry.

Mission markers remain visually prominent above buildings for gameplay
readability. They are not collision geometry.

## Performance / API gates

- Upstream output is built once from the static, bounded nine-building
  Suburbania source and reused each frame.
- The new adapter is entirely pure JavaScript, without browser or clock access.
- Source files load from the same origin; the service worker caches them after
  the first successful visit and is bumped to `gfta6-static-v0.1.5`.
- The upstream module's unchanged Git blob is verified with Node's built-in
  SHA-1 implementation using Git object framing.
- Automated tests verify stable building IDs and X/Y footprints across
  modes, unchanged game/cargo snapshots, upstream stable depth sorting, and
  car/building painter ordering with a headless Canvas test double.
- No claim of measured 60 FPS or visual browser acceptance is made until
  an actual timed browser play-through is recorded.
